# 磨砂玻璃壁纸设计

## 第三版：竖屏自适应

用户已接受玻璃效果，并选择“额度优先”。新增 `frosted-glass-v3.html`，默认按用户提供的 **1600×2560（5:8）** 预览，保留第二版的玻璃质感、透明度控制与区域设置。

### 布局规则

- 纯壁纸视图（`?wallpaper`）始终铺满实际浏览器视口；不要求手动填写分辨率。预览页可切换目标尺寸。
- 用 `ResizeObserver` 根据壁纸容器的宽、高重新计算设计单位，字号、圆角、内边距、磨砂半径、模块间距同步缩放。窗口尺寸与 Windows 显示缩放变化会触发更新。
- 日期/天气锚定上方；额度与硬件锚定下方，以内容所需高度排布。额度区保留最小高度，避免固定百分比导致内容裁切。
- 背景使用 `object-fit: cover` 居中等比填充：比例不同时裁切边缘，不拉伸原图。此原图的眼睛、嘴与下巴区域保留在上下模块之间。
- 宽高比大于 5:8 时逐渐压缩设计单位，在 3:4 达到 12% 压缩，为人物留出垂直空间；较长的竖屏将额外空间留给背景。
- 三个区域的透明度设置沿用第二版存储键，切换分辨率或刷新后仍保留。预览分辨率选择单独保存；纯壁纸视图忽略这一选择，始终跟随视口。
- “跟随竖屏窗口”在横向预览窗口中回退到 1600×2560。纯壁纸视图的布局设计与测试范围为竖屏。

通过 Chromium 浏览器检查：画布填充、模块边界、文字裁切、区域重叠、原图保护区、分辨率选择与材质保存；无 JavaScript 错误。

| 9:16 | 720×1280、1080×1920、1440×2560、2160×3840 |

## 第二版：玻璃材质

## 外观

延续用户原图、淡紫色强调、上中下布局与面部留白。玻璃采用更轻的烟灰底色、局部背景模糊、细颗粒、斜向柔光、随角度变化的边缘高光与轻阴影。文字和数字不随玻璃透明度变淡。

## 手动调节

打开 `frosted-glass-v2.html` 可在右侧调节，窄屏时控制区位于预览下方。

- 范围：所有模块 / 日期与天气 / AI 套餐余量 / 本机性能。
- 透明度：0–100%，越高越通透，只控制玻璃底色。
- 磨砂强度：0–64 个设计像素；背景模糊与透明度独立调节。
- 边缘高光：0–100%。
- 清透 / 柔雾 / 深雾预设；恢复默认作用于当前选择的范围。
- 当前设置保存于浏览器本机存储。默认：透明度 75%、磨砂 34、高光 50%。

透明度 100% 时底色完全透明，背景模糊与玻璃高光仍受各自参数控制。若希望背景完全清晰，可将磨砂强度设为 0。

页面预留 WE `applyUserProperties` 回调，识别 `glass_transparency`、`glass_blur`、`glass_highlight`。本轮只验证回调逻辑；未导入 WE 或添加真实宿主用户属性配置。
