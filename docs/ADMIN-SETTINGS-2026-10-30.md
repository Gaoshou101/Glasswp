## 后续更新：设置页体验优化（2026-11-08）

实现「后续建议」的第 1–3 项。只改设置页静态文件（`public/admin/index.html`、`admin.js`），桥接 API 与配置格式不变。

- **统一账号列表**：原「CPAMP」区的关注勾选与别名、原「卡片显示顺序」区合并为「账号」区。每行包含关注勾选、显示位次、可编辑别名、平台、套餐、凭据文件与上移/下移；已关注账号按显示顺序排在前面，其余按 CPAMP 顺序排在后面。不读取 CPAMP 也能调整已关注账号的别名、顺序或取消关注；加入新账号需先「从 CPAMP 读取账号」。读取结果中缺失的已关注账号标为「最近一次读取未在 CPAMP 中找到」。
- **搜索与筛选**：按别名、平台、套餐或凭据文件搜索（不区分大小写），并按平台、关注状态筛选，显示「显示 N / M 个账号」和「清除筛选」。筛选时上下移动只越过相邻的可见已关注账号，隐藏账号保持原有相对顺序。
- **一次保存**：关注、别名和顺序合并为一个草稿，「保存账号设置」一次提交，「撤销更改」恢复已保存状态。别名留空时沿用原别名，不计为更改。新勾选、尚无快照的账号显示「保存后同步套餐」。保存失败保留草稿，可直接重试。
- **未保存提示**：天气城市、CPAMP 连接、账号、用量自动刷新、硬件传感器分别显示「未保存」标记，顶部状态栏汇总并链接到对应区块；离开或刷新页面时浏览器提示。比较对象是已保存配置，把值改回原样即取消标记。某一区块保存后重新读取配置，不会覆盖其他区块的草稿。
- **破坏性操作确认**：桥接在更换面板地址、重新填写凭据或清除凭据时会清空关注账号；现在执行前用确认框说明会取消的账号数（以及会放弃的未保存账号更改），取消则不发请求。只改尾部斜杠等等价地址不计为更换，也不提示。
- **诊断折叠**：「壁纸连接」先显示可读状态——前端类型、运行/暂停、分辨率、帧率、最近上报时间与构建、最近读取快照、缓存故障数；超过 5 分钟未上报或存在缓存故障时以警示色标出。原始 JSON 放入默认折叠的「高级诊断」，每 15 秒在后台更新。传感器原始读数折叠为「原始传感器读数（N 项）」。用量刷新只直接列出未更新的账号，全部结果折叠在「各账号结果：X 个已更新 · Y 个未更新」中，展开状态不受每 3 秒轮询影响。
- **小修正**：未检测传感器前禁止「保存传感器选择」，避免把已保存的选择误存为自动；已保存但当前未检测到的传感器保留为单独选项。城市搜索按钮不再被挤成两行。工作室页轮播选项文字由「每页最多四项额度」改为与实现一致的「五项」。

验证：`tests/admin_settings_check.py` 重写为自带静态服务（临时端口提供 `dist/`），全部 API 使用匿名夹具，12 组检查通过、浏览器错误 0；已加入 `scripts/verify.ps1 -Browser`。覆盖套餐按 ID 对应、读取合并与缺失标记、搜索/平台/关注筛选、筛选中排序与焦点、撤销、勾选/别名回退、保存失败重试与重开、跨区块草稿保留、真实的离页提示、凭据变更确认、传感器检测前禁用保存、可读诊断与折叠、刷新结果折叠后不被轮询收起、文本安全、360/540/900/1440 宽度及图标。完整 `verify.ps1 -Browser`：26 项前端测试、270 项桥接检查及 6 组浏览器回归通过。首轮运行时 `liquid_glass_check.py` 出现一次负载相关的时序失败，单独运行与第二轮完整运行均通过。
