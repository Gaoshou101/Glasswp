# Glasswp 1.0.0

首个正式桥接安装包，由 GitHub Actions 在 Windows runner 从发布标签构建。

## 下载与安装

下载 **Glasswp-Bridge-v1.0.0-win-x64.zip**，完整解压后双击 `install-bridge.cmd`。安装会请求一次管理员授权，完成桥接安装、启动与登录自启动配置，并打开本机设置页。

- 支持 Windows x64；自包含程序无需另外安装 Node.js 或 .NET。
- 默认安装到 `E:\WallpaperDashboard`。没有 E 盘时，在解压目录执行 `./install-bridge.cmd -RuntimeRoot D:\WallpaperDashboard`，改成实际可用盘符。
- `-Check` 只检查；`-NoAutostart` 不新增或修改自启动任务。
- 使用原 Windows 用户升级，保留已有配置与展示票据。
- Wallpaper Engine 需单独安装；包内 `payload/wallpaper` 是票据为空的通用壁纸，在管理页复制展示票据后填写到壁纸属性。

## 本版内容

- 世界时钟、多来源天气、AI 套餐余量与硬件监控。
- 本机管理页配置来源、账号、主题及传感器。
- 统一安装和升级入口，安装包哈希校验、失败回退及私有目录保留。
- 三款主题展示与图文安装指南。

## 校验与限制

同名 `.zip.sha256` 用于检查下载完整性；`Glasswp-Bridge-v1.0.0-build-info.json` 记录源码提交、构建 ID 与程序文件哈希。

云端执行前端、桥接无桌面检查、安装编排、打包和隔离进程回退测试。原生桌面鼠标/窗口事件及真实 UAC、用户计划任务需要在实际桌面验收；部分温度读取依赖设备、驱动和管理员权限。安装包未作代码签名。

账号、密钥、展示票据和缓存不随发布包分发。第三方协议与图标声明随包附带；背景图片权利归原作者所有。
