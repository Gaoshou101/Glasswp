## 2026-10-22 上层应用误触壁纸

- 原因：WE 会向壁纸转发上层窗口的 `mouseup`，原兼容层只检查网页坐标，直接补发卡片点击。
- 修改：桥接新增带原展示票据鉴权的 `/v1/desktop-input`，按点击时真实鼠标位置查询最上层窗口。仅 Explorer 桌面根窗口允许激活；原生鼠标点击与孤立松开均检查，确认前不显示按压反馈。暂停、失焦或更新的点击会撤销未完成的激活。
- 第一版使用全局鼠标钩子；用户报告桌面卡片也无法点击，因此该方案已替换为按需 `GetCursorPos/WindowFromPoint` 检查，不注册鼠标输入钩子、不轮询。
